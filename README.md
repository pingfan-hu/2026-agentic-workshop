# Agentic Workflows with Claude Code

A hands-on workshop on working with AI coding agents, taught at The George Washington University with the [GW Trustworthy AI Initiative](https://trustworthyai.gwu.edu).

**Workshop website:** <https://pingfan-hu.github.io/2026-agentic-workshop>

AI agents can read your files, write your code, and build your outputs. This workshop teaches you how to put them to work on real projects: setting up an agentic workflow, packaging repeatable tasks into skills, and keeping your data safe and your judgment in charge along the way. Every part mixes short lectures with hands-on practice, so you leave having actually built something.

## What we will cover

### Part 0: Setup

Pre-workshop preparation so you can follow along hands-on: read a short Anthropic article on agentic coding, then install Claude Code (the AI agent), Positron (a data science IDE), and a few optional companions.

### Part 1: Agentic Basics

What an agent is and how it differs from a chat assistant, how to set up and launch one in a real project, and a live example of building a website by prompting an agent. Closes with a first look at agentic skills.

### Part 2: Skill Usage and Design

Skills turn workflows worth keeping into reusable commands. You will use existing skills, install ones shared by the community, and author your own from scratch.

### Part 3: Working Safely with Data and AI

How to work with agents as a data scientist without losing control: build pipelines instead of one-off results, keep sensitive data out of the chat, and codify a full project (data in, scripts, output out) that you can rerun and reproduce. Features an interactive map project you will rebuild yourself, then reproduce for a new dataset.
